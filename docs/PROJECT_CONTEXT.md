# Ngữ cảnh dự án cho phiên làm việc tiếp theo

BrewLite 1.0 là bài tập nhóm 6 người, yêu cầu 10 Task trong `docs/IMPLEMENTATION_PLAN.md`. **Chỉ sửa repo `BrewLite_swe-project_1`**. Repo này ban đầu chỉ có 9 export Stitch; đã thêm Next.js frontend và NestJS backend (backend auth/products được lấy làm nền từ dự án BrewLite bên cạnh, sau đó sửa trong repo này). Không sửa `BrewLite_swe_project_2`.

Nguồn giao diện: `stitch/*/code.html`, `screen.png`, `stitch/artisanal_vietnamese_coffee_ordering/DESIGN.md`. Frontend `frontend/src/app`; state giỏ Zustand `frontend/src/stores/cart.ts`; domain model `frontend/src/types/domain.ts`; service interface/adapters `frontend/src/services`. Auth là API thật, còn Orders/Payments/Promotions/Loyalty/Barista là demo localStorage hoặc REST adapter chưa có server. `NEXT_PUBLIC_DATA_MODE` là `mock` hoặc `api`, không fallback ngầm.

Backend Prisma `backend/prisma/schema.prisma`, migration `backend/prisma/migrations`, auth `backend/src/auth`, products `backend/src/products`, seed Barista qua biến môi trường. Role CUSTOMER/BARISTA. Mọi đơn mới PENDING, thanh toán xác nhận mới PAID; PAYMENT_FAILED giữ giỏ; UNKNOWN không tự thành công; PAID → PREPARING → READY → COMPLETED. Hủy chỉ từ PENDING/PAID/PAYMENT_FAILED. Giá tiền số nguyên VND. Backend tương lai tính giá và tồn kho lại.

Kiểm tra đã chạy: frontend build, backend build và 37 backend unit/integration-style tests và 3 frontend mock tests qua; Compose đã chạy 3 container; PostgreSQL migration/seed, HTTP smoke auth/Products và bcrypt DB qua. Playwright đã qua 3 bài mock và 2 bài API mode trên desktop/mobile. Frontend lint sạch; xem `docs/TESTING.md`. Ưu tiên: mở rộng E2E sang backend Orders/Payments thật; TV4/TV5/TV6 bổ sung Orders/Payments/History-Promotion-Loyalty server theo `docs/API_CONTRACT.md`.
